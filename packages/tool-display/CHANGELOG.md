English | [简体中文](CHANGELOG_zh.md)

## 0.1.2

### Fixed

- `mini` / `low` summary rows and `medium` blocks now follow pi's `outputPad` setting, so they line up with native rows.
- `medium` durations now use pi's recorded tool duration. They match bash's `Took` time and stay correct after reload or resume.
- The extension no longer adds tools to the active set, so `--tools` and `defaultTools` behave exactly as in pi.

### Changed

- The package now ships its changelog, so later updates can show release notes in pi.
