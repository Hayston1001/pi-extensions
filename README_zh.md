# pi-extensions

[English](README.md) | 简体中文

个人 [pi](https://pi.dev) 扩展集合. `packages/` 下每个目录就是一个独立发布的 npm 包.

| 包 | 作用 | 安装 |
| --- | --- | --- |
| [`pi-timeline`](packages/timeline) | 消息时间线: 列出会话的消息节点, 精确跳转  | `pi install npm:pi-timeline` |
| [`pi-token-meter`](packages/token-meter) | token 工作行实时计量与单轮结算行展示 | `pi install npm:@hayston/pi-token-meter` |
| [`pi-thinking-display`](packages/thinking-display) | 只保留正在流式输出的 thinking 段, 以及折叠标记, 悬停高亮与点击展开 | `pi install npm:pi-thinking-display` |
| [`pi-tool-display`](packages/tool-display) | 工具调用展示密度: mini/low/medium/default | *coming soon* |
