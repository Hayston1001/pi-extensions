# pi-extensions

English | [简体中文](README_zh.md)

A collection of personal [pi](https://pi.dev) extensions. Each directory under `packages/` is an npm package published on its own.

| Package | What it does | Install |
| --- | --- | --- |
| [`pi-timeline`](packages/timeline) | Message timeline: lists a session's message nodes and jumps to one precisely | `pi install npm:pi-timeline` |
| [`pi-token-meter`](packages/token-meter) | Live token metering on the working line and a settlement line per turn | `pi install npm:@hayston/pi-token-meter` |
| [`pi-thinking-display`](packages/thinking-display) | Keeps only the thinking block that is currently streaming, plus fold markers, hover highlight and click to expand | `pi install npm:pi-thinking-display` |
| [`pi-tool-display`](packages/tool-display) | Density of tool call rendering: mini/low/medium/default | *coming soon* |
